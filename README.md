## 🌱 About

Hi — I'm **Prathamesh Deshmukh** ([@Ped20](https://github.com/Ped20)), a **research data
scientist** from Pune, India, working at the intersection of **statistics, R programming,
and plant-breeding analytics**.

I turn experimental field data into **selection decisions**: from first look at a dataset
to hypothesis tests, predictive models, and interactive tools that non-coders can actually
use. Everything I build is **reproducible, versioned, and in the open**.

> *"Turning field data into selection decisions."*

## 🧭 What I do

| Pillar | What it means in practice |
|---|---|
| 📊 **Statistical analysis** | EDA, ANOVA + post-hoc ranking, regression, clustering & PCA |
| ♻️ **Reproducible research** | self-contained scripts, versioned data, clean `results/` outputs |
| 🎛️ **Interactive delivery** | R Shiny dashboards so stakeholders explore data without coding |
| 🌾 **Domain depth** | plant genotype/phenotype analysis, trait selection, abiotic stress |

## 📂 Portfolio

One coherent pipeline — 100 plant genotypes from raw data to a stakeholder-ready dashboard —
shipped as five reproducible modules:

| # | Project | What it does | Outcome |
|---|---|---|---|
| 1 | [Exploratory Data Analysis](https://github.com/Ped20/Project-1-Exploratory-Data-Analysis) | summaries, correlation, distributions | clean first look |
| 2 | [ANOVA & Post-Hoc Test](https://github.com/Ped20/Project-2-ANOVA-Post-Hoc-test) | one-way ANOVA + Duncan's ranking | which groups differ |
| 3 | [Linear Regression](https://github.com/Ped20/Project-3-linear-regression) | simple + multiple models, diagnostics | predict height |
| 4 | [Clustering & PCA](https://github.com/Ped20/Project-4-Clustering-and-PCA) | K-Means + PCA on scaled traits | group similar lines |
| 5 | [Shiny Dashboard](https://github.com/Ped20/Project-5-shiny-dashboard) | interactive "Plant Trait Explorer" | no-code exploration |
